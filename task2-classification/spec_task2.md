# 规格书 · 任务二：地物分类（随机森林）

> 状态：已实现（与 `classify.py`、`leakage_demo.py` 对齐；评估结果见 `evaluation_report.md`）
> 最后更新：2026-06-07

---

# 目标

基于 4 波段反射率影像，用随机森林对每个像素做三类地物分类（其他 / 植被 / 水体），并通过对比两种训练/测试切分方式，量化并证明像素级随机切分带来的空间数据泄漏。

---

# 输入

| 项目 | 说明 |
|------|------|
| 影像文件 | `scene.tif` |
| 波段数 | 4：波段1=Red、波段2=NIR、波段3=Green、波段4=SWIR |
| 像素值 | 反射率，已定标，**无需额外缩放/偏移** |
| 标签文件 | `labels.tif`，单波段 |
| 类别数 | 3 类：`0=其他`、`1=植被`、`2=水体` |
| nodata | 无 |
| 有效像素总数 | 40000（推测为 200 × 200） |

类别占比（已用 `count_labels.py` 统计）：

| 类别 | 含义 | 像素数 | 占比 |
|------|------|--------|------|
| 0 | 其他 | 9976 | 24.94% |
| 1 | 植被 | 29361 | 73.40% |
| 2 | 水体 | 663 | 1.66% |
| 合计 | — | 40000 | 100% |

> 上表绝对像素数为 `count_labels.py` 实测值（非占比反推）。

> 关键观察：类别**严重不平衡**。植被占 73.4%，水体仅 1.66%。这直接决定了评估不能只看 accuracy（见评估指标节），也决定了水体类需要单独设验收门槛。

---

# 方法

- **模型**：随机森林（`RandomForestClassifier`，`n_estimators=100`）。
  - **选择理由**：随机森林对特征量纲不敏感、能处理非线性边界、对类别不平衡有一定鲁棒性、训练快且无需调参即可给出强基线；非常适合作为像素分类的首选基线模型。
- **特征**：仅使用原始 4 个波段（Red, NIR, Green, SWIR），每个像素是一个 4 维特征向量。
  - **不添加 NDVI 等衍生指数**。理由：随机森林可从原始波段自行学习波段间的非线性组合，NDVI 等指数是 Red/NIR 的确定性函数，不引入新信息；本任务刻意保持特征最小化，以聚焦于"切分方式"这一核心变量。
- **样本构造**：将每个有效像素展平为一行，4 波段为特征列，`labels.tif` 对应值为标签列，得到 40000 × 4 的特征矩阵与长度 40000 的标签向量。

---

# 训练/测试怎么切分

**核心前提：像素之间不是独立的。** 遥感影像存在强烈的空间自相关——相邻像素极可能属于同一地物、反射率高度相似。因此若随机打散像素来切分，训练集和测试集会包含大量"空间上紧邻、信息几乎重复"的像素对，测试集等于在变相考训练时已见过的邻居，导致**数据泄漏**和精度虚高。

本任务**必须实现两种切分并对比**：

1. **随机像素切分（错误做法，作为反面对照）**
   - 在全部 40000 个像素上做随机 70/30 划分（如 `train_test_split`，固定 `random_state`）。
   - 预期：精度偏高，但因泄漏而**不能代表真实泛化能力**。

2. **空间块切分（正确做法）**
   - 将影像按 **10 × 10 网格**划分为 100 个空间块（每块约 20×20 像素）。
   - 按**块**随机抽取 70% 的块作训练、30% 的块作测试（固定随机种子保证可复现）。
   - 同一块内的像素整体进入训练或测试，避免训练/测试像素在空间上相邻。
   - 预期：精度低于随机切分，更接近真实泛化表现。

两种切分使用**相同的模型配置与特征**,唯一变量是切分方式,以便公平对比。

---

# 评估指标

只看总体 accuracy 不够——在 73.4% 多数类占比下,无脑全预测为植被就能得 73.4% 的"高"准确率,却完全识别不出水体。因此需综合以下指标:

| 指标 | 说明 |
|------|------|
| 混淆矩阵 | 3×3,查看各类互相误分情况(尤其水体被误判为何类) |
| 每类 precision / recall / f1-score | 分别针对类别 0/1/2,重点关注少数类水体(2) |
| 总体准确率 (overall accuracy) | 全体测试像素正确率 |
| 基线准确率 (majority baseline) | 全部预测为多数类(植被)= **73.40%**,作为 accuracy 的最低参照线 |

每种切分方式都需输出上述全套指标,便于横向对比。

---

# 验收标准（可执行）

| 编号 | 标准 | 判定方式 |
|------|------|----------|
| 1 | 模型总体准确率 **> 73.4%**(超过多数类基线) | 读取测试集 overall accuracy,与 0.734 比较 |
| 2 | 水体类别(2)的 **recall ≥ 0.5** | 从分类报告中读取类别 2 的 recall |
| 3 | **空间块切分的准确率显著低于随机像素切分** | 同模型、同特征下,`acc(随机) - acc(空间块)` 为正且差距明显,以此证明随机切分存在数据泄漏 |

> 说明:标准 1、2 主要针对正确做法(空间块切分)的模型质量;标准 3 是本任务的核心结论,需两种切分都跑出来才能验证。

---

# 非目标

本任务**不**包含:

- 深度学习方法(CNN、U-Net 等)。
- 超参数调优(`n_estimators` 固定 100,不做网格搜索/交叉验证调参)。
- 添加 NDVI、EVI、SWIR 比值等衍生特征。
- 多余的可视化(仅在确需验证结论时绘图,如对比柱状图;不做制图美化)。
- 类别不平衡的重采样/加权处理(SMOTE、class_weight 等暂不纳入)。
- 影像预处理(已定标,不做大气校正、重投影、去云)。
